# 게스트 진입·음성 차트·말버릇 및 꼬리질문 검증

2026-11-01 사용자 요청 1~6. PROJECT.md §5(개인정보·공급자 게이트), §2.5(꼬리질문), §2.6·§7.7(결과·게스트), P0·P3·P5에 따른다.

- 음성 박스는 결과 차트 그리드 전체 폭을 사용한다. 요약 음량과 답변별 타임라인은 실제 표시 폭으로 경과 초를 계산하고 호버 위치에 세로선·시간을 표시한다. 좌우 방향키·Home·End로도 탐색 가능하다.
- 영역별 근거는 6개 영역 레이더의 AI 생각 아코디언 안에 둔다. 인용·미관찰·판단 근거 데이터는 보존한다.
- 입장 잠금 통과 후 저장된 회원 세션이 없으면 게스트를 자동 발급한다. 공급자가 설정돼 있어도 게스트는 서버 계정 속성으로 항상 Mock을 강제한다. 동의 API와 서버 합성 fixture 판정도 게스트 전송을 열지 못한다. 게스트에서도 개인정보 검사는 유지하고, 상단에 개인정보 입력 주의·탐지 한계 경고를 표시한다. X는 현재 페이지의 경고만 닫으며 검사를 끄지 않는다. 로그인·가입 버튼으로 회원 진입이 가능하다.
- 단독 `그`는 지시 관형사/대명사인지 군말인지 전사 텍스트로 안정적으로 구별할 수 없어 집계하지 않는다. 화면과 태도 보정은 같은 탐지기를 사용한다. 실제 군말인 `그…`도 놓칠 수 있는 보수적 선택이다. 다른 사전 단어의 문맥 오탐 가능성은 남는다.

## 실제 꼬리질문 검증

`node tools/followup-smoke.mjs`를 1회 실행했다. 개인정보 없는 새 합성 답변만 사용하고, 프로필 분석·학교 검색·질문 생성·평가·보고서 코멘트는 Mock으로 두어 실제 호출은 `dialogue.next`에만 썼다. 기존 사용자 계정·기록·자료를 조회하거나 전송하지 않았다. 실제 HTTP 요청 수는 **8/10**, 모두 200. 재시도 포함 상한은 fetch 직전 강제한다. 결과 원본은 `docs/verification/2026-11-01-followup-smoke.json`이다. 이 작업에서 재실행하지 않는다.

| 단계 | 관찰 |
|---|---|
| 도입 | 다음 질문으로 진행, 꼬리질문 없음 |
| 학업 | 부족한 실험 결과 설명에 원인 분석 행동·추가 탐구를 묻는 꼬리질문 생성 |
| 경험 | "팀에서 좋은 결과"라는 답변에 본인 역할을 묻는 꼬리질문 생성 |
| 성찰 | "다음에 더 잘"이라는 답변에 미수행 원인·개선 계획을 묻는 꼬리질문 생성 |
| 꼬리질문 답변 3개 | 모두 다음 본질문으로 진행, 연속 꼬리질문 없음 |
| 마무리 | 면접 종료, 꼬리질문 없음 |

응답 시간 약 0.96~1.92초, 서버 출력 검증 통과 후 실제 API에서 `ask_followup`을 받았다. 한 세션·세 부족 사례에 대한 동작 확인이며 일반적인 품질·한국어 STT 정확도·실기기 음성을 검증한 것은 아니다. 질문 계획은 규칙 기반을 사용했다. 합성 시험 인스턴스의 실모델 동작과 게스트의 Mock 경로를 구분한다.
