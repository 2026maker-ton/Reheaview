# 텍스트 마지막 답변의 자동 종료 화면 (2026-11-04)

범위: PROJECT §7.7, P3·P5, 최종 답변 제출 → 근거 기반 보고서.

현재 서버는 마지막 `turn.text`에서 답변 저장과 최종 평가를 한 요청 안에서 처리한다. 브라우저는 이 요청의 응답 전까지 면접실에 머물러, 실 AI 평가가 지연되면 마지막 질문에 답해도 끝나지 않는 것처럼 보였다. 빠른 Mock 응답만으로는 드러나지 않았다.

`room.js`는 서버가 보낸 closing 단계의 답변 제출에서 인정 문장 낭독이 끝나면 처리 중 화면을 먼저 표시한다. 상태는 completing이며 응답 전 completed/성공 보고서로 표시하지 않는다. 정상 turn.text 본문·버전·블라인드 검사·평가 게이트는 유지한다. 완료 응답 뒤에만 보고서를 읽는다. 요청 오류는 입력 본문과 면접실을 복구하고, 블라인드 거절은 기존 안내·같은 질문 재답변 경로를 따른다. 일반 질문의 화면 이동은 바꾸지 않는다.

변경 파일: `public/screens/room.js`, `tools/e2e-room-cases.mjs`, `tools/e2e-ui.mjs`(의도된 합성 503 응답 구분), `PROJECT.md`, 본 기록. 브라우저 시험은 지연된 마지막 텍스트 응답, 실제 제출 본문, 성공 후 보고서 조회, 503 시 입력 보존, 블라인드 거절 복구를 검사한다. 서버 AI 지연 자체를 줄이거나 함수 중단·저장 장애까지 해결했다고 주장하지 않는다. 실제 외부 AI 호출은 0회이며 배포·실기기 검증과 구분한다. 과거 문서의 테스트 수치는 이력으로 유지한다.

검증: `npm run check:project` 4/4, `npm test` 390 통과/0 실패, `npm run e2e` 205 체크 통과/0 실패. 모두 Mock·스텁이다. 현재 변경의 프로덕션 배포·실키·실음성 검증은 미실행이다.
