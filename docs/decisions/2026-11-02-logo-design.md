# Reheaview 로고 기반 시각 디자인

사용자가 제공한 루트 `logo.svg`를 서비스 로고로 채택한다. PROJECT.md §3·§7.7, P1 핵심 UI·P5 반응형 데모 작업이다. 제품 대상·기능 범위·평가·공급자 정책은 바꾸지 않는다.

## 디자인 결정

- 로고 원본의 라임 `#D7F56D`·먹색 `#1D2017`을 브랜드색으로 쓴다. 밝은 중립 바탕 `#F7F8F2`, 흰 카드, 짙은 올리브 `#3E5419` 링크·관찰 지표를 함께 쓴다. 오류·경고의 의미색은 유지한다. 밝은 라임 위에는 먹색 글자를 쓴다.
- 정적 로고를 헤더·입장·로그인·대시보드·개인정보 페이지에 적용하고 SVG 파비콘을 제공한다. 대시보드의 비대칭 말풍선 패널과 둥근 순서 표식은 로고 형태를 따른다. 실제 녹음 신호나 성과 수치를 장식으로 만들지 않는다.
- 대시보드는 학생부·활동 경험에서 질문을 찾고 실제 답변을 돌아보는 일을 설명한다. 경험 입력 → 근거 확인·승인 → 면접·코칭 순서와 새 면접 버튼을 제공한다. 임시저장·진행 중 면접·최근 결과는 기존 동작을 유지한다.
- 입력·근거·준비·면접·결과·동의 대화상자에 공통 색·간격·카드·버튼을 적용한다. 면접실은 질문 중심으로, 결과는 실제 말하기 기록과 인용 근거 중심으로 유지한다. 6축 미관찰·규칙 기반·검증 전 참고용 설명은 보존한다.
- 본문·한국어 제목은 기존 Pretendard, 영문 워드마크는 로컬 Trebuchet MS, 시간·순서 숫자는 로컬 monospace를 사용한다. 새 외부 글꼴·이미지·분석 서비스는 추가하지 않는다.
- 홈 이동을 실제 링크로 바꿔 키보드 Enter로 접근할 수 있게 한다. 모바일 헤더를 두 줄로 정리하고, 390px에서 버튼·링크·설명 버튼의 터치 영역과 대비를 검사한다. 기존 reduced-motion 설정을 유지한다.

## 보호 조건

지원 자료 원문·출처·인용·답변 revision·판단 보류를 변경하지 않는다. 게스트 AI·만 18세 이상 확인·음성 처리 동의·개인정보 경고·삭제·공급자 모드 표시도 유지한다. 외부 AI 호출 없이 Mock·주입 스텁으로 검증한다. 사용자 작업 중이던 package.json·package-lock.json은 수정하지 않는다.

`public/index.html`(화면·로고·아이콘), `public/logo.svg`(제공받은 원본 복사), `public/styles.css`(공통 디자인·반응형), `public/privacy.html`(로고·아이콘·공통 헤더), `tools/e2e-ui.mjs`(로고·키보드·모바일·7화면 검사), `tools/e2e-room-cases.mjs`(Mock HTTP 응답 처리 대기), `PROJECT.md`(현재 디자인 기준), 이 결정 기록을 변경한다. 루트 `logo.svg` 원본은 수정하지 않는다.

- `npm test`: 379 통과 / 0 실패 / 0 건너뜀(Mock·스텁).
- Chromium E2E: 180 체크 통과 / 0 실패. 로고·파비콘 응답·키보드 홈 이동·가입·샘플·근거 승인·면접·결과·재시도·음성 실패 복구를 포함한다. 7개 화면에서 1440·768·390px 가로 넘침, 390px 대비·44px 터치 영역을 확인한다.

## 랜딩 단독 재디자인 — 말하기 전의 무대

사용자의 “과거 스타일에 얽매이지 말고 랜딩만” 요청에 따라 위 대시보드 히어로 설명을 이력으로 남긴다. 현재 소개 페이지는 이미 분리되어 있던 `#/landing`이다. P1·P5, PROJECT §3·§7.7의 지원서 주장 → 질문 → 근거 기반 코칭을 소개하는 작업이며 제품 방향 변경은 없다.

- 전체 폭 라임 무대에 큰 한국어 제목과 중앙 입체 로고를 배치한다. 이미지 프레임을 없애고 CSS 마스크·multiply로 배경을 연결한다. 원본 PNG는 수정하지 않는다. 이어지는 밝은 바탕에는 가상 활동 문장 → 질문 예시, 실제 연습 3단계, 시작 버튼을 둔다. 가짜 성과 수치·추천사·AI 채점 주장은 없다.
- 색상: 라임 `#D7F56D`, 먹색 `#1D2017`, 본문 바탕 `#F8F9F3`, 보조 글자 `#525941`, 예시 바탕 `#ECEFE3`. 제목·본문 Pretendard, 영문 워드마크·순서 숫자 Trebuchet MS. 이미지와 큰 제목에 시각적 강조를 집중하고 반복 카드·장식 애니메이션은 쓰지 않는다.
- 전용 `public/landing.css`를 추가해 `#screen-landing`과 랜딩이 보일 때의 헤더·본문 배치에만 적용한다. 기존 전역 스타일·대시보드·입력·면접·결과 코드와 라우터는 이 작업에서 수정하지 않는다. 개인정보 경고·연령·AI 동의·실제 모드 표시는 유지한다.
- 이번 변경 파일: `public/index.html`, `public/landing.css`, `tools/e2e-ui.mjs`, `tools/check-project.mjs`, `PROJECT.md`, 이 결정 기록. 이미 작업 중이던 랜딩 라우팅 변경은 보존하고 검사 기준을 소개 랜딩 + 앱 7화면으로 맞춘다.

## 랜딩 헤더·로그인 진입·글꼴 후속 수정

사용자 요청으로 랜딩 헤더는 로고와 “무료로 시작하기” 링크 하나만 표시한다. 본문 시작 버튼도 같은 문구로 통일하고 로그인으로 연결한다. 앱 헤더의 AI 모드·개인정보·계정 제어는 앱 화면에서 표시한다. 별도 개인정보 경고와 동의 절차는 보존한다. 게스트의 로그인 진입은 세션·초안을 삭제하지 않는다. 회원은 기존대로 대시보드로 보낸다. 새로고침 시 게스트 로그인도 유지하도록 부팅·라우트 가드를 맞춘다.

랜딩 제목·본문·버튼은 로컬 SUIT Variable 글꼴로 교체했다. `public/assets/SUIT-Variable.woff2`와 공식 `SUIT-LICENSE.txt`를 함께 배포한다. 외부 글꼴 요청 없이 로컬에서 로드한다. 이전 Pretendard 설명은 이력이다.
