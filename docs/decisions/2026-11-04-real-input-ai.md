# 일반 입력 AI와 ElevenLabs 음성 허용

요구사항: P0-4·P3·P1-2. 사용자가 샘플 전용 AI 문구의 이유를 확인하고 일반 입력에서도 AI를 사용하도록 명시적으로 요청했다. 이어 ElevenLabs가 브라우저 음성으로 대체되는 현상도 함께 수정하도록 요청했다.

## 원인

`providers/gate.js`는 LIVE_ACK만 켜져 있고 REAL_DATA_ACK가 꺼져 있으면 서버가 판정한 샘플만 허용한다. 일반 입력은 `synthetic_only`로 차단한다. ElevenLabs의 기존 로컬 설정은 REAL_DATA_ACK=false였고 `vercel.json`에는 이 설정이 없었다. 이 경우 TTS API는 204로 응답하고 브라우저가 기기 음성으로 대체한다. 안내 문구는 실제 차단 사유를 반영하고 있었다. 문자열만 지워서는 ElevenLabs가 재생되지 않는다.

## 변경

- 운영자의 명시적 허용 요청에 따라 현재 활성 공급자 Gemini·Claude·Groq·ElevenLabs의 LIVE_ACK와 REAL_DATA_ACK를 로컬 `.env.local`에 추가하고 `vercel.json`에도 비밀이 아닌 배포 설정으로 명시한다. 기존 비밀 파일을 열거나 출력하지 않고 비밀이 아닌 설정만 추가한다. 보류된 DeepSeek는 새로 켜지 않는다.
- 학교 검색에도 같은 요청을 적용하도록 GEMINI_GROUNDING_ACK를 명시적으로 켠다. 검색 결과의 표시·보관·질문 근거 재사용 제한은 유지한다.
- 키·URL·모델·음성 ID 설정은 기존 값을 사용한다. 키를 코드·브라우저에 넣지 않는다. 일반 질문·답변도 기존 서버 소유 컨텍스트와 공통 caller 경로를 이용한다. 일반 면접의 답변 분석·꼬리질문, 평가·보고서, 질문 설계, 학교 검색, STT·TTS 경로에 같은 승인 설정이 적용된다.
- 사용자 화면의 샘플 전용 문구는 서버 입력 처리 설정 안내로 바꾼다. 동의·성인·설정 누락·예산·AI 스위치·실패로 차단되면 사실대로 표시하며 브라우저 음성을 ElevenLabs라고 표시하지 않는다.
- `evaluateGate`와 합성 판정·권한 검사는 변경하지 않는다. 샘플 위장 입력으로 차단을 우회하지 않는다. 기존 수동 브라우저 음성 선택도 유지한다.

## 처리 조건 및 배포

Gemini에는 승인된 유료 처리 프로젝트 키가 필요하다(PROJECT §5). 이 변경은 서버의 실제 입력 허용 설정이며 공급자 계정의 결제 상태·데이터 보존·국외 처리 계약을 검증하거나 변경하지 않는다. 결제 상태를 확인했다는 의미의 GEMINI_PAID_ACK나 무료 허용 설정은 추가하지 않았다. 기존 키와 사용자가 이미 설정한 공급자 계정의 처리 조건을 따른다. 실자료나 마이크 음성을 검증 목적으로 전송하지 않는다.

Vercel의 기존 Production 인스턴스는 파일 수정만으로 바뀌지 않는다. 수정 코드를 새로 배포해야 한다. 연결된 계정의 Production 권한이 없어 원격 환경변수 변경·승격은 수행하지 않는다. 로컬은 프로세스를 재시작해야 `.env.local` 변경이 적용된다. 이미 프로세스 환경변수로 명시한 false 값이 있다면 그것이 로컬 파일보다 우선하므로 운영 환경에서 함께 확인해야 한다.

## 검증 가이드

기존 전체 회귀·공급자 게이트·TTS 계약 시험과 문서 가드를 실행한다. 새 테스트케이스나 Mock은 만들지 않는다. 명시적 false 설정 시 외부 요청 0건이라는 기존 계약을 보존한다. 키 없이 설정만 켰을 때 실제 연결 완료를 주장하지 않는다. 성인·동의가 없는 요청, 고입 입력, 킬 스위치, 예산·오디오 상한, 서버 소유 발화 제한도 그대로 검사해야 한다. 일반 프로필의 활성 공급자 상태와 선택한 TTS 음성 재생은 새 배포 환경에서 확인한다. 실제 외부 생성 AI 요청은 이 작업에서 기본 0회로 한다. 실행 결과는 작업 보고에 남긴다.

실행 결과: `npm test` 387 통과·0 실패, `npm run check:project` 4/4, 변경 JS 문법 검사·`git diff --check` 통과. 배포 JSON을 `loadConfig`에 통과시켜 4개 활성 공급자의 LIVE_ACK·REAL_DATA_ACK, Gemini grounding, ElevenLabs TTS 라우트가 켜짐을 확인했다. 실제 Chrome에서 샘플 전용 문구 제거·음성 옵션 6개·페이지 오류 0건을 확인했다. 이 브라우저 점검은 실제 키 없이 수행했고 미연결 상태를 ElevenLabs라고 표시하지 않는 것도 확인했다. `onboard check`는 로컬 키 및 SDK 선언·사용을 확인했다. 새 테스트케이스·Mock 파일은 추가하지 않았다. 외부 생성 AI 요청 0회, 실제 음성 생성·재생과 Production 동작은 미검증이다. 전체 UI E2E는 기존 삭제된 modeChip 검사 문제로 이번에 실행하지 않았다.

변경 파일: `vercel.json`, `.env.example`, `public/core/copy.js`, `public/core/tts.js`, `src/domain/tts-voices.js`, `PROJECT.md`, 이 결정 기록. 로컬 비밀 없는 설정은 git 제외 파일에만 추가했다. 과거 TTS ADR의 REAL_DATA_ACK=false 보류 문구는 당시 이력이며 최신 PROJECT 결정을 우선한다.
