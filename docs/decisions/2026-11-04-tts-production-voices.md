# Production TTS와 음성 선택 (P3·P1-2)

사용자 요청: Production에서 목소리가 적용되지 않는 현상 수정 및 음성 선택 추가.

## 원인과 변경

- `.env.local`은 git에 포함되지 않는다. 커밋·승격만으로 서버 API 키나 활성화 설정이 전달되지 않는다. Vercel Production 계정 설정은 접근 권한 부족으로 직접 확인하지 못했다.
- 캐시된 provider 상태가 live가 아니면 브라우저가 TTS API 호출 자체를 생략했다. 이제 브라우저 음성을 명시적으로 고른 경우를 제외하고 서버에 요청하며, 서버가 최신 게이트를 판단한다.
- `vercel.json`에 비밀이 아닌 `TTS_PROVIDER=elevenlabs`, `ELEVENLABS_LIVE_ACK=true`를 명시한다. 모델·URL·기본 음성에는 서버 기본값을 제공한다. 명시적으로 빈 값인 설정은 보존한다.
- 면접 준비의 음성 선택: 운영자 기본 음성, George, Sarah, Daniel, Charlotte, 브라우저 기본 음성. 선택은 기기 localStorage에 보관한다. 키만 서버에 전송하고 서버 허용 목록으로 실제 음성 ID를 결정한다.
- 인증된 `/api/v1/tts/status`가 프로필 소유권과 동의·합성 여부를 확인하여 상태·목록을 제공한다. 응답에는 키를 담지 않는다. 실패 시 브라우저 대체 이유를 표시한다.
- 기존 서버 소유 발화 대상·고정 안내문 제한, 성인/동의/실데이터 게이트, 비용 상한, 요청 취소, 오디오 크기 제한은 유지한다. 개인정보 안내를 실제 TTS 처리 범위에 맞췄다.

## Production 적용 조건

1. Vercel 프로젝트의 **Production** 서버 환경변수에 `ELEVENLABS_API_KEY`를 Secret으로 등록한다. 채팅·코드·클라이언트 환경변수에 입력하지 않는다.
2. `ROUTE_SPEECH_SYNTHESIZE`가 명시되어 있다면 `elevenlabs`인지 확인한다. 명시적인 빈 모델·URL·음성 ID는 제거하거나 유효한 값을 지정한다.
3. 실제 지원 자료가 포함된 질문은 운영자의 처리 조건 검토와 적절한 안내·동의 이후에만 `ELEVENLABS_REAL_DATA_ACK=true`로 허용한다. 이 변경에서 해당 게이트를 자동 해제하지 않았다.
4. 수정 커밋으로 새 Production 배포를 만든다. 기존 배포 승격만으로 수정 코드가 반영되지는 않는다.

## 검증과 한계

- 최종 회귀: `npm test` 387개 통과, `npm run check:project` 4개 통과. 변경 JavaScript 구문 검사 및 `git diff --check` 통과.
- 실제 Chrome에서 기존 앱과 인증 API를 사용해 선택 항목 6개, Sarah 선택·localStorage 저장·화면 갱신 후 유지, Mock 상태 안내를 확인했다. 페이지 오류 없음. 신규 테스트케이스나 Mock 구현 없이 한 번의 브라우저 점검을 실행했다.
- `onboard check --env-path .env.local` 통과: 로컬 키와 SDK 선언·사용이 확인되었다. Production 키 검증을 의미하지 않는다.
- 기존 UI E2E는 이미 제거된 `#modeChip`을 기다리는 단계에서 중단된다. 페이지/콘솔 오류나 예상하지 않은 HTTP 오류는 관찰되지 않았다. 전체 E2E 통과로 간주하지 않는다.
- 실제 합성은 서버 고정 인사말로 2회 시도했으나 네트워크 `EACCES`로 차단되었다. 실제 지원 자료·답변은 전송하지 않았다. 성공적인 외부 합성 및 음질 확인은 미검증이다.
- Vercel Production 환경변수·배포 접근 권한이 없어 원격 설정 변경·커밋 푸시·승격은 수행하지 않았다.

## 수동 확인 가이드

새 Production 배포에서 합성 예시 프로필로 시작한다. 면접 준비에서 Sarah를 고른 뒤 재방문해 선택 유지와 상태 안내를 확인한다. 면접의 고정 안내문이 선택한 ElevenLabs 음성으로 재생되는지 확인한다. 브라우저 기본 음성을 고르면 외부 합성 없이 브라우저 음성으로 바뀌어야 한다. 실제 자료의 승인이 없다면 브라우저 대체 사유가 표시되어야 한다. 임의 음성 키와 타 사용자 프로필 조회는 각각 422/404로 거부되어야 한다. 별도 테스트케이스/Mock은 추가하지 않았다.
