# 학교·전형·인재상 정보의 Gemini 검색 통합

요구사항: P2 공식 자료 탐색, P1-6, PROJECT §2.3·§4.4. 사용자는 자료 원문에만 의존하던 인재상과 학교·전형 정보를 모두 Gemini 검색 기반으로 요청했다.

## 이전 동작과 변경

이전에는 `school.analyze`가 입력한 글에서 인재상을 추출하고 별도 `school.search`가 참고 결과를 제공했다. 검색 결과는 클라이언트에서 줄별로 파싱·재구성하고 인재상 문구를 잘라 추가 버튼으로 제공했으며, 서버는 결과를 2,000자로 잘랐다. 실패하면 서버와 클라이언트가 각각 반복 요청했다.

이제 근거 확인의 첫 구역에서 학교·전형·인재상을 하나의 Gemini Google 검색 결과로 제공한다. 새 프로필에서 원문 분석을 먼저 호출하지 않고 검색을 기본 실행한다. 독립 자료 원문 추출 API와 수동 버튼은 유지한다. 공식 모집요강·입학처 공지와 대학·학과 공식 홈페이지를 조사하며 대학 공통 인재상·학과 교육목표·전형 평가기준을 구분한다. 다른 학년도·전형의 비율을 가져오거나 전형 미입력 시 임의 선택하지 않도록 요청한다.

본문은 HTML을 이스케이프하고 줄바꿈을 유지해 그대로 표시한다. 항목 파싱·문구 자동 추가·응답 절단을 제거했다. 출처 링크·추천 검색어는 당회 응답에만 제공하고 개인 이력에는 텍스트만 보관한다. 검색 1회에 provider 호출 1회로 제한하며 실패·차단과 재검색 버튼을 표시한다. Gemini 이외 라우트는 검색을 호출하지 않는다. 키·동의·성인·실데이터·GROUNDING_ACK·비용 게이트를 해제하지 않는다.

## 검색 결과와 면접 질문의 경계

2026-11-04 [Gemini API 공식 약관](https://ai.google.dev/gemini-api/terms)을 재확인했다(현재 URL은 `https://aistudio.google.com/docs/terms`로 연결). Grounding 조항은 검색 결과·추천 검색어의 분석 및 다른 목적 이용, 검색 링크를 이용한 자동 수집을 제한하고, 별도 허용 없는 본문 변경·중간 삽입을 제한한다. 따라서 검색으로 찾은 정보를 보여 주되 자동으로 질문 생성 근거나 검증된 원문으로 전환하지 않는다. 질문에는 독립적으로 입력·확인한 원문과 직접 입력한 역량을 사용한다. 이 경계를 우회하는 자동 수집·재분석은 구현하지 않았다.

현재 약관의 사용자 이력 텍스트 보관 예외는 최대 2년이다. 기존 서비스의 더 짧은 150일 설정과 프로필 TTL·삭제 정책은 유지한다. 이전 grounding ADR의 6개월 제한·2026-04-28 버전 표기는 과거 설명이며 현재 상한에 관한 설명은 이 기록을 따른다. 검색 출처가 있다고 해서 해당 대학 공식 자료와 문장을 서버가 대조 검증했다는 뜻은 아니다. 공식 사이트·전형 일치 검수와 실제 검색 품질은 별도 확인이 필요하다.

## 검증

검증 결과: `npm test` 387 통과·0 실패(기존 검색 스텁 계약 포함), `npm run check:project` 4/4, 변경 JavaScript 문법 검사·`git diff --check` 통과. 새로운 테스트케이스·Mock은 작성하지 않았다. 실제 Chrome 390px에서 기존 합성 fixture와 로컬 앱으로 검색 구역 최상단 배치, 설정 차단 안내, 검색 버튼, 가로 넘침 0px, 페이지 오류 0건을 확인했다. 새 프로필에서 `school-search` 요청은 1회, 자동 `school-analysis` 요청은 0회였다. 첫 수동 점검의 멱등 헤더 누락과 두 번째 점검의 검사 선택자 오류는 점검 코드에서 바로잡아 완료했다.

전체 UI E2E는 이번 작업에서 미실행이다. 이전 실행에서 확인된 삭제된 `#modeChip` 대기 문제가 있어 전체 통과를 주장하지 않는다. 실제 외부 생성 AI HTTP 요청은 0회이며 새 검색 프롬프트의 공식 자료 탐색 품질·실서비스 과금·Production 동작은 미검증이다. 브라우저는 공급자 키와 GROUNDING_ACK를 끈 상태였고 검색 성공 계약은 기존 스텁 회귀로만 확인했다.

변경 파일: `src/providers/prompts/interview.js`, `src/app/handlers/profiles.js`, `public/screens/evidence.js`, `public/core/info-text.js`, `public/styles.css`, `PROJECT.md`, 이 결정 기록. 과거 PROJECT/ADR의 원문 추출 중심 UI·6개월 보관 상한 설명은 이력이며 이번 PROJECT 머리말과 이 기록을 우선한다. 배포·커밋·푸시는 수행하지 않았다.

추가 확인 가이드: 공식 자료가 없는 학과/전형의 미확인 표시, 대학 공통 인재상과 전형별 기준 구분, 길고 여러 줄인 응답의 문자 보존·이스케이프, 출처 없는 응답 거부, 검색 실패 시 자동 반복 없음, 과거 이력과 새 출처의 분리, 모바일 줄바꿈, 타 사용자 접근 404, 검색 결과가 질문 계획에 들어가지 않음.
