- 입장 비밀번호(화면·`/api` 잠금·Vercel 503)를 사용자 지시로 제거했다. 로그인·연령(만 18세)·AI 동의·블라인드 검사·공급자 게이트는 그대로다.
- 첫 로그인 온보딩은 이름 → 출생 연도 → 학생부 3단계다. 학생부 단계는 `/documents/extract`(기존 경로)로 글자만 뽑아 칸에 넣고 원본은 저장하지 않는다. 활동·특기 단계와 완료 조건은 제거했으나 저장된 값은 지우지 않는다.
- 연결 문장은 받은 답변을 인정하는 앞문장만 말한다. "이제 …에 대해 여쭤보겠습니다" 류 다음 주제 예고는 `ackOnly`가 제거한다(Mock 뱅크·모델 출력·저장된 계획 모두).
- 학교·전형 검색은 입학처 공개 자료만 근거로 삼도록 프롬프트를 바꿨고(`school-search-v3-admissions-only`), 화면에서 인재상 원문 근거(사용자 자료)와 검색 결과(미검증)를 구분해 표시한다. 검색 결과는 역량 근거·질문 근거로 승격하지 않는다.
- 꼬리질문: Claude Haiku `decideTurn` 추가, 프롬프트 v3(답변 구절 인용 `quote`·좋은/나쁜 예·일반 문장 금지), 서버가 인용이 답변에 실제로 있는지 검증. 게이트(동의·만 18세·REAL_DATA_ACK·LIVE_ACK)는 그대로.
- `AI_REQUIRE_LIVE`(서버·Vercel 기본 on): AI 스위치가 켜져 있으면 Mock·규칙 폴백 대신 503 `ai_unavailable`. 음성 입출력(speech.*)은 제외. 스위치를 끄면 규칙 기반.
- 구글 검색 추천 미리보기 iframe은 링크를 새 탭으로 열게(`<base target=_blank>`) 해 클릭해도 사라지지 않는다. 저장 금지는 유지(방금 검색한 화면에서만 보임).

## 2026-11-03 후속 (사용자 지시)
- AI 기능 기본 공급자는 Claude(`CLAUDE_MODEL`=`claude-haiku-5-5`)다: 꼬리질문·주장·학교 분석·질문 설계/작성·평가(관찰·채점)·질문별/보고서 한줄평. 학교·전형 검색만 Gemini(Google 검색 연결)다. `ROUTE_*`로 바꿀 수 있다.
- 학교·전형 검색 결과(Gemini)는 핵심 역량·인재상 영역에 항목별 표로 **수정 없이 전부** 보여 준다(미검증 표시). 약관(질문 생성·분석에 자동 사용 금지)을 지키기 위해 면접 질문·역량 적합성에는 사용자가 "+ 추가"를 눌러 직접 추가한 항목만 쓰인다. 검색이 비면 서버가 1회 더 시도하고 화면에는 실패 문구를 보이지 않는다.
- 질문 구조: 학업·경험·성찰 단계가 모든 대학 역량을 나눠 맡고(`competency_ids`), 결과의 역량 적합성은 그 단계의 답변으로 계산한다("다루지 않음" 대신 질문 미진행은 드물게만 표시).
