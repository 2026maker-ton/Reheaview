# 블라인드 학교 단서 오탐 보정 (2026-11-01)

적용 범위는 PROJECT.md §5.7·§6.1·§7.7, P0 안전 및 P1-8 탐지 정확성이다. 지원서 주장과 답변의 실제 근거를 훼손하지 않으면서, 식별 정보의 저장·외부 전송 차단을 유지한다.

## 확인한 상태

사용자가 제시한 "네, 제가 생명과학부에 지원하게 된 계기는 고등학교 때 '유전자 가위(CRISPR)' 기술을 주제로 발표를 준비했던 경험 덕분입니다"는 작업 시작 시 로컬 코드에서 이미 통과했다. 당시 작업 폴더에는 학교 일반 표현 예외를 포함한 미커밋 변경이 있었다. 사용자 환경의 실행·배포 버전은 확인하지 않았다.

같은 로직에서 "처음 고등학교", "특히 고등학교", "먼저 고등학교"는 학교명으로 오탐했다. 공백을 없앤 우회 검사에서는 "과학 고전"을 "과학고"로 잘랐다. 반대로 모든 조사·어미 끝 글자를 제외하는 규칙은 대전·송도·용인고등학교를 놓쳤다.

## 변경

- 일반 부사와 명확한 문장 연결 표현을 학교명 후보에서 제외한다. `전·도·인` 같은 한 글자만으로 학교명을 제외하지 않는다.
- 학교명은 원문에서 하나의 이름 또는 한 글자씩 벌린 이름과 학교급을 함께 찾는다. 문장 전체를 붙여 앞 문구를 학교명으로 만들지 않는다. 원문 위치를 아는 경우 기존 가림 처리를 적용한다.
- 학교 유형 우회 검사는 글자 사이 공백·기호를 허용하되 원문과 뒤쪽 조사·어미·단어 경계를 확인한다. 위치를 가리지 못한 우회 표현은 기존처럼 `unmasked`로 처리해 AI 전송을 멈춘다.
- 식별 정보·가족 직업 차단, 필터 오류 시 차단, 원문 없는 이벤트 기록과 공급자 게이트는 유지한다. 필터 버전을 `blind-filter-2026-11-01.1`로 올린다.

## 검증 및 한계

회귀 검사는 제시한 문장·일반 경험 설명의 통과와 원문 보존, 실제 학교명·분리 표기 차단, 정상 문장 뒤에 식별 정보가 추가된 경우의 차단을 확인한다. API 검사는 가짜 키·스텁 공급자만 쓰며, 허용 답변 revision과 공급자 입력이 원문과 같고 차단 답변은 저장·호출되지 않는지 검사한다. 브라우저 검사는 Mock 경로에서 CRISPR 답변이 팝업 없이 결과까지 보존되는지 확인한다.

규칙 기반 휴리스틱이므로 새로운 학교명·말투·우회 방식에 대한 오탐과 누락은 남는다. 이는 대학별 공식 규정의 검증이나 개인정보 완전 익명화를 의미하지 않는다. 실모델 호출·실마이크·배포 버전 검증은 이 변경의 시험 범위에 포함하지 않는다.

검증 결과: `npm run check:project` 4/4 통과, `npm test` 361 통과·0 실패, `npm run e2e` Chromium Mock 105개 체크 통과·0 실패(CRISPR 원문 보존 포함). 첫 API 검사 실행은 샌드박스의 로컬 HTTP 접속 `EACCES`로 실패했으며, 로컬 접속 허용 후 8/8 통과했다. 실제 공급자 호출은 없었다. 기존 문서의 과거 테스트 수·공급자 배치·음성/배포 미검증 기록은 당시 이력으로 유지한다.
