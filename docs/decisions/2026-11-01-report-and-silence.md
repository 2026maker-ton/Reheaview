# 30초 정적 대기와 결과 화면 개편

2026-11-01 사용자 요청 1~6, PROJECT.md §2.5·§2.6·§7.7(P3·P4·P5)에 따른다.

- 초기 무발화와 발화 후 정적은 모두 연속 30초를 기다린다. 초기 무발화 음성은 전사하지 않는다. 발화 후에는 전사 뒤 문장 종결 여부와 무관하게 제출하며, 전체 질문 60초 제한은 우선한다.
- 결과 첫 부분은 실제 답변의 시간 초과 수·평균 길이·말버릇 수·최장 정적 평균을 크게 보여 준다. 음성 없는 경우 미측정을 표시한다.
- 면접 요약·답변 차원별 관찰·서류와 답변 나란히 보기·분석의 한계 구역을 제거한다. 평가기·미관찰·참고용 고지는 카드와 도움말에 유지한다. 서버 근거·revision·평가 데이터는 보존한다.
- 개인정보 유출 검사 결과를 질문과 답변 위로 이동한다. 블라인드 기준의 개인정보 검사이며 음성 전사는 별도 동의로 먼저 처리됨을 설명한다. 완전한 유출 방지를 보장하지 않는다.
- 질문은 기본 접힘 네이티브 details/summary로 제공한다. 펼치면 근거·답변·코멘트·음성 구간을 볼 수 있다. 마지막 행동 버튼은 세부정보 아래에 둔다.
