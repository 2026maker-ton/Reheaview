# 초기 30초·발화 후 3초와 가족 배경 탐지

사용자 요청: 잡음을 제외한 마지막 말소리 뒤 3초에 답변 종료, 최초 무발화 30초 자동 넘김 유지, ‘국회의원 아들’ 전사 문장의 미탐 수정, 앞으로 실제 테스트 AI 호출 10회 미만. PROJECT.md §2.5·§5·§6.1·§7.7, P0 개인정보 사전 차단·P3 답변 수집·P5 동작 검증에 해당한다. 주장 → 질문 → 답변 → 근거 기반 코칭은 유지한다.

## 원인과 동작

- `createCapture`는 최초 대기와 발화 후 정적에 같은 `silenceMs=30_000`을 썼다. 이를 `initialSilenceMs=30_000`과 `silenceMs=3_000`으로 나눴다. 최초 30초에 말이 없으면 전사 없이 다음 질문으로 넘기고, 발화 후 3초에는 문장 종결 여부와 관계없이 녹음을 종료해 전사·제출한다. 다시 말하면 후속 3초 대기를 갱신한다. 60초 전체 제한·동시 stop의 최종 오디오 공유·종료 의사 우선 처리는 유지한다.
- 잡음 억제는 기존 브라우저 `noiseSuppression`·`echoCancellation`과 소리 크기·연속성·현재 주기성 판정으로 한다. 과거 `spoke`를 현재 목소리로 취급하지 않는다. 50ms 프레임·100ms 주기성 표본 경계와 녹음 종료 이벤트, 전사·답변 API 지연은 별도다. 3초는 녹음 종료 조건이지 결과 응답 시간 보장이 아니다. 비주기적 소음을 넣은 합성 시험은 통과했으나 모든 팬·음악·다른 사람 음성을 제거한다는 뜻은 아니다.
- 제시된 전체 전사 문장은 수정 전 `blindGate`가 `blocked:false`를 반환했다. 가족 호칭에 아들·딸 관계가 없고 직업 사전에 국회의원이 없어 정방향·역방향 모두 놓쳤다. 직업 목록에 정치 관련 직업을 추가하고, ‘직업 + 의(선택) + 아들/딸/자녀 등 + 관계 서술’의 인용 구간을 찾는다. 띄어쓰기 우회도 원문 구간으로 처리한다. 단순 ‘국회의원 자녀 특혜 기사를 분석’ 등 연구 주제와 학교급 추억·학술 표현은 계속 통과시키는 회귀를 유지한다.
- 기존 중앙 검사(`detectBlindRisk` → `blindGate`)를 확장했으므로 답변 사전 차단·지원 자료 마스킹·결과 가림이 같은 규칙을 사용한다. 필터 버전은 `blind-filter-2026-11-01.2`다. 차단 답변은 revision으로 저장하지 않고 답변 분석 AI에도 보내지 않으며, 이벤트에는 분류·횟수만 남긴다. 실제 음성의 Groq 전송은 전사 전에 별도 동의를 거치는 기존 흐름이고, 음성이 전사 이전에 개인정보 검사를 받는다고 주장하지 않는다.

## 테스트 호출 한도

AGENTS.md에 기본 Mock·스텁(0회), 작업 실행 전체의 실제 AI HTTP 요청 합계 최대 9회(검색·STT·재시도·대체 모델 포함)를 기록했다. 여러 도구를 재시작해 한도를 초기화하지 않는다. 운영 면접의 호출 예산 설정은 바꾸지 않았다.

8개 수동 실호출 도구에 `live-test-budget.mjs`를 연결했다. 네트워크 직전에 횟수를 예약해 동시 요청·실패·재시도도 합산하고 열 번째 요청은 전송 전에 거절한다. 로컬 앱의 `/api/v1/` 요청은 제외하지만 로컬 AI 프록시의 `/v1/messages` 등은 포함한다. 외부 redirect 자동 추적도 막는다. 학교 검색은 최대 9개 샘플, STT 반복은 최대 9회이며 공급자별 기존 승인·동의 게이트는 그대로다. 과거 8/10 스모크 기록은 이력이며 이번에 재실행하지 않았다.

## 검증과 변경 파일

가짜 키·합성 파형·가상 시계·공급자 스텁으로 검사한다. 전사 API의 합성 응답에 사용자 제시 문장을 넣은 뒤 실제 답변 명령 처리까지 보내, 차단·후속 AI 호출 0회·답변 revision 없음·원문 이벤트 없음·같은 질문 재답변을 확인한다. 브라우저는 해당 문장의 안내 팝업과 결과 원문 미노출, 초기 무발화 29초 미제출·30초 자동 넘김, 발화 후 2.9초 미제출·3초 경계 후 전사/제출 1회, STT 무응답 복구·최종 결과 이동을 확인한다. 예산 시험은 가짜 fetch로 열 번째 요청이 전송되지 않는지 검사하며 실제 네트워크를 쓰지 않는다.
